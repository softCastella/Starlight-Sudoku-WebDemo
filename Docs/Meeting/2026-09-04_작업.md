## 설정·타원 버튼 (2026-09-04 오후)

양피지 안 패딩은 테두리 최소선. 남는 공간은 내용 블록을 상하좌우 가운데. 설정은 창을 조금 높게(`aspectRatio: 1.18`) 써서 위에 붙지 않게 했다.

타원 버튼(`OvalButtonLayout`): 15px로 문구를 재고, 양끝 별·뾰족한 부분(가로 19%씩)을 뺀 뒤 버튼을 키운다. 상한에 닿으면 글자를 11까지 줄인다. 닫기는 이 크기로 가운데. `AspectRatio`로 양피지 가로를 채우지 않는다.

타이틀 별소리(twinkle chime)는 음원 끝 페이드가 아니라, 반짝임 200ms 뒤 180ms 동안 줄이다가 끊는다. 클립은 약 0.9초라 끝만 줄이면 꼬리가 더 길어진다.

BGM/SFX 스위치는 0.82 배율, 오른쪽 정렬.

## 후속 작업

**내일 (2026-09-05) — 웹 BGM 게이트**

HTML 오버레이를 Flutter 타원 위에 또 그려서 화면과 소리가 같이 깨졌다. **코드는 내일.** 오늘은 여기만.

화면

- BGM ON/OFF 뒤 **흰 사각**, 버튼이 **가로로 커짐**
- 원인: 전체 화면 HTML `<button>` (`72vw`, 브라우저 기본 흰 배경). 양피지 모달이 아니다
- 내일 화면: 지금 구현된 타원 두 개만 (ON 위, OFF 아래, 음표 없음, 폰 프레임 안). HTML 버튼 DOM/`mountGate` 삭제

소리

- ON은 HTMLAudio로 난다
- **OFF를 눌러도 음원이 나온다.** Flutter 캔버스와 HTML 오버레이가 **같은 클릭을 둘 다** 받는다. OFF를 눌러도 아래 ON `pointerdown`이 `startTitleFromGesture()` → `play()` 를 다시 켠다. 앱 전체 `GameBgm.unlock()`도 웹에서 `WebHtmlBgm.play()` 한다
- 내일 소리: 숨은 `HTMLAudioElement`만. ON `pointerdown`에서만 `play()`. OFF는 `stop()` + `_enabled = false`. `unlock()`은 꺼져 있으면 재생하지 않음

하지 말 것: 게이트 UI를 새로 만들기, 랜딩 CSS, APK 스플래시·타원 크기를 음원 때문에 키우기. `main`에 APK·문서, `pages`에는 웹 화면이 바뀌는 커밋만.

**실기기**

- 갤럭시 USB 연결 후 arm64 APK 설치. 타이틀·쉬움 테두리·10판 모달(스테이지)·설정을 본다

## 웹은 스플래시·음성 없음 (2026-09-04 밤)

웹은 흰 로고 스플래시와 Tyche Spark 보이스를 쓰지 않는다. 타이틀 위에 BGM ON/OFF부터 시작한다. HTML 부트도 `#0E2040`. 스플래시와 식별 음성은 APK만.

웹 BGM 게이트는 Material 버튼이 아니라 **같은 타원 버튼 두 개**. 음표 아이콘을 한쪽에만 넣지 않는다. TextButton은 기본이 투명해서 호버 전에 안 보인다.

웹 BGM ON이 안 들린 이유: `audioplayers`는 파일을 다 연 뒤에야 `audio.play()`를 한다. 그 사이 브라우저가 탭을 제스처로 버린다. 숨은 `HTMLAudioElement.play()`로 소리는 살릴 수 있다.

**회귀 (Pages, 내일 고침):** HTML 버튼을 겹쳐 그려서 흰 사각·큰 버튼. OFF를 눌러도 Flutter ON이 같은 클릭으로 `play()` 한다.
