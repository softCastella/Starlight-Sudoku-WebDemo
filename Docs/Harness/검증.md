# 하네스

소스 오브 트루스는 이 문서와 `Docs/`, 코드다. 작업마다 아래 순서를 지킨다. 회의록에만 있고 여기 없으면 회귀를 못 막는다. 새로 정한 기본값은 **이 목록에 항목으로 넣는다.**

## 작업 방식 (약속)

1. **시작 전:** 이 문서를 처음부터 읽는다. 최신 작업 기록(`Docs/Meeting/`)도 본다. 읽기 전에 코드를 바꾸지 않는다.
2. **구현.**
3. **끝:** 이 목록을 화면별로 검증한다. “이번에 안 건드렸다”고 건너뛰지 않는다. 난이도·스테이지·마을 하늘은 항상 같이 본다.
4. 답하기 전에 통과한 것과 깨진 것을 적는다.

아래 **무조건**은 이번 일과 무관해 보여도 깨면 안 된다. 입점 기준, 지금 구현된 디자인, 코어 루프가 그것이다. 여백 슬라이더 값처럼 아직 맞추는 것만 예외다.

최신 작업 기록: `Docs/Meeting/2026-09-10_작업.md`. 일시정지·다시 풀기: `Docs/Meeting/2026-09-10_후속작업.md`(구현됨). 전날: `Docs/Meeting/2026-09-09_작업.md`. 편집 도구: `Docs/Meeting/2026-09-08_UI편집도구_현황.md`. 지금은 실기기 APK 테스트만. Play 콘솔은 그다음. 입점 상세: `Docs/Deployment/2026-09-04_Play_디자인검토.md`.

- 스토어 AAB에 벌레 스킵·언어 디버그·UI 슬라이더 없음. 스크린샷은 **설치된 APK**, 퍼즐 화면 포함. 마을만 넣지 않는다. 웹 주소창으로 찍지 않는다.
- 시스템 뒤로가기·제스처를 쓴다. 타이틀에 커스텀 「뒤로」를 또 달지 않는다. 종료 확인 양피지는 실수 종료 방지라 허용.

- 출시 서명. 키스토어는 git에 없음. Play 512 아이콘은 정사각 풀블리드(모서리 안 깎음). FREE/NEW 홍보 뱃지 금지. 「체험판」 리본은 상품 구분.
- 터치 48dp, 글자 대비율. `theme-color` `#0E2040`.

## 무조건 — 코어 루프

- **APK:** 흰 스플래시 → 타이틀. **웹:** 스플래시·식별 음성 없음. BGM ON/OFF 다음 타이틀. 오프닝은 **새 퍼즐 시작** 다음(건너뛰기 가능). 스플래시 직후가 아니다.
- 난이도 → 스테이지(이전 판 클리어 필수) → 퍼즐 → 클리어 → StarLight. 진행은 이어하기에 저장.
- 체험판: Easy 10만. Normal/Hard 숨김. 10판 후 종료 모달은 **스테이지 선택**만.
- 하늘·창문 = **스테이지 클리어 비율만**. 건물 복원량으로 `max` 하지 않는다. 빵집 등 라벨은 StarLight 복원.
- StarLight 숫자·힌트/실수 감점은 `GameBalance`. UI에 숫자를 새로 박지 않는다.
- 마을 보기는 타이틀에서 들어간다. 미션으로 건물을 복원한다. 달빛 항구 실제 지도는 아직 없다.

## 무조건 — 지금 구현된 디자인

아래 화면 항목이 그것이다. 타이틀 별, 스플래시 흰색, 웹 폰 프레임, 양피지·타원, 설정, 쉬움 셀 가이드, 마을 글자, 스테이지 카드 별을 이번 일과 무관하게 바꾸지 않는다.

- **긴 글자로 타원을 늘릴 때: 가운데만 늘린다.** 별 끝은 짧은 버튼(「닫기」「다음」)과 같은 크기. 그림 전체를 `BoxFit.fill`로 가로 늘리면 실패. `Image.centerSlice`도 실패(작은 타원에서 그림이 사라짐). 좌·중·우 세 장. **모달 안 타원**과 **마을 미션**도 같다(`kOvalCompactWidth` 80, 가로는 글자 길이). 양피지 창도 모서리는 두고 가운데만. 모달 패딩 40(타원 여백보다 넓음). 짧은 확인 창을 화면 높이까지 늘리지 않는다. 모달 버튼을 `FittedBox`/`Expanded`로 제각각 만들지 않는다. BGM처럼 칩 폭만 쓰는 타원은 한 장 그대로.

## 스플래시

- **APK만 흰 화면.** 타이틀 밤하늘·남색으로 바꾸지 않는다. 로고가 작게 나타났다가 타이틀로 간다.
- **웹은 스플래시 없음.** HTML 부트도 `#0E2040`. 첫 화면은 타이틀 위 BGM ON / 그 아래 BGM OFF. **같은 타원 버튼 두 개.** 음표 없음.
- 웹 BGM·SFX는 숨은 `HTMLAudioElement`만 쓴다(`#starlight-html-bgm` / `#starlight-html-sfx`). 게이트 UI를 HTML로 다시 그리지 않는다. (`mountGate`는 내일 제거. 지금은 Pages 회귀)
- 웹 데모 나가기: 「퍼즐을 나가시나요? / 저장은 되지 않습니다.」 이어하기 없음.
- 웹 데모 5판 끝: 「데모플레이는 여기까지입니다. / 정식 체험판을 구글스토어에서 만나보세요!」
- 웹 BGM ON은 BGM과 효과음을 같이 켠다. **BGM·SFX 모두** HTML 스트리밍(`preload="none"`). `audio.load()`·`<link rel="preload" as="audio">`·선로딩 금지. ON `pointerdown`에서 `play()`로 HTTP range.
- 식별 음성(`Tyche Spark Splash Voice`)도 **APK만.** 로고 등장 때 **한 번만** 재생. 스플래시를 눌러도 다시 나지 않는다. SFX 끄면 없음. `inactive`만으로 끊지 않는다. 스플래시가 끝나면 끊고 타이틀 BGM.

## Play UI

편집 도구 사용·저장·슬라이더 의미: `Docs/Meeting/2026-09-08_UI편집도구_현황.md`. 코드: `lib/presentation/config/play_ui.dart`. 화면마다 폰트 크기를 새로 정하지 않는다.

- 보조 11 / 본문 13 / 라벨 14 / 타원·모달 버튼 **11** / 타이틀 두루마리 **15** / 제목 18. **11 아래로 줄이지 않는다.**
- 양피지 패딩은 테두리 최소선. 남는 칸은 내용 블록을 상하좌우 가운데.
- 타원·모달 **버튼 글자**는 슬라이더 값 그대로다. 기본 **11**. 타이틀 두루마리는 **15**(버튼 11로 줄이기 전 값). 타이틀에 19·18을 더하거나, 영어를 타원 끝에 맞춰 줄이지 않는다. 긴 영어는 두 줄. 타원 끝 비율은 별 여백만.
- 버튼 폭·높이 배율은 언어마다 다를 수 있다. 한 숫자로 모든 언어를 덮지 않는다. 2026-09-09 폰 JSON `locales`를 `play_ui_baked.dart`에 넣었다(타이틀 두루마리는 한만 208.86, 다른 언어는 200). 설정·크레딧 패딩·간격도 언어별. 공통 `button` 11·모달 패딩 40은 `PlayUi`에 남긴다.
- 두루마리·타원 글자는 **그림 세로 가운데**. 위로 올라가 잘리면 실패. `scaleDown`은 칸을 넘을 때만 줄인다. 기본 세로 오프셋 **0**. 타원 `Text` height는 **1**(1.05·큰 음수 오프셋으로 위에 붙지 않게).
- 숨은 조절 도구는 로컬 튜닝용이다. 스토어 화면·스크린샷에 넣지 않는다. 편집 화면 AppBar는 **초기화** / **저장** 글자. 저장은 값을 보관하고 화면에 보여 준다. JSON은 **locales가 앞**, common은 기본값. 채팅에 붙이면 잘린다. 폰은 `Android/data/com.tychespark.starlightsudoku/files/play_ui_tune.json`에도 남긴다(USB로 이 파일은 됨. SharedPreferences는 출시 앱이라 안 됨). 언어 칩 옆 **가져오기**.
- UI 편집은 **별도 전체 화면**이다. 위는 지금 고르는 버튼·양피지 미리보기, 아래는 그 화면 슬라이더다. 게임 타이틀 버튼을 하단 패널로 가리지 않는다.
- 미리보기는 360×640 칸을 바깥 `FittedBox`로만 맞춘다. 기기 전체 크기를 그대로 넣으면 폭·패딩이 안 보인다. 글자만 바뀌고 폭·패딩·제목이 그대로면 실패.
- 언어는 한/EN/日/简/繁. 버튼·양피지 크기·글자·패딩은 **화면마다, 언어마다** 따로다. 저장은 그 값 전체를 남긴다.
- **이 화면**은 마지막 저장 스냅샷으로 지금 칩만 되돌린다. **초기화 → 이 화면만**은 지금 칩만 기본값. **모든 화면**은 두 번 확인한다. 다른 화면을 건드려도 이미 맞춘 화면이 기본값으로 돌아가면 실패.
- 슬라이더는 Material `Slider`를 쓰지 않고 **지름 22 크림 원 + 금테**다. 핸들 없는 회색 막대면 실패.
- 양피지 안 패딩은 슬라이더 값 그대로다. 가로 12%·세로 16% 바닥값을 씌우지 않는다. 그래야 여백 슬라이더가 먹는다.
- 위치 슬라이더: 모달 가로/세로, 버튼 글자 가로/세로. 종료·포기·클리어·설정 양피지와 타원·두루마리 버튼이 같이 따른다.

## 설정

- 타이틀·퍼즐 AppBar 설정. BGM·SFX는 위, 스위치 0.82·오른쪽.
- 유저 ID+번호+복사는 한 줄. 길면 `…`(복사는 전체). 개인정보처리방침은 그 아래. **웹에는 유저 ID 행 없음**(일회성 데모, 생성·저장도 안 함). APK만.
- 설정·크레딧 양피지는 **글+패딩 높이(허그)**. 비율 **0.98 고정 금지**(아래 빈 칸 생김). `topCenter`. 제목 위는 옛 창 높이(`폭/0.98`)의 **12%**. 허그 시 아래는 공통 **40**까지 맞춤(베이크 16만 쓰면 하단 말이 잘림). 제목 18·닫기 11 가운데. 스위치를 크레딧처럼 가운데 두지 않음. 웹은 ID 행이 없어 설정이 더 짧다.
- **크레딧**을 누르면 저작권 창. 게임명·티케웍스·티케스파크·`© Tyche Spark. All rights reserved`. 짧은 가로 양피지에 맞춰 글자를 축소하지 않는다. 제목 18, 게임명 14, 본문 12(토큰 13에서 1 줄임), 저작권 11. 본문은 저작권보다 크고 제목·게임명보다 작다. **11 아래 금지.** 제목·게임명·저작권·닫기는 **가운데**. 제작·음성 본문은 **왼쪽**(블록은 가운데). 제목 위 여백은 옛 창 높이(`폭/0.98`)의 약 12%. 아래는 공통 40까지(빈 장식 공간·과컷 없음).
- WebDemo는 앱 `main`의 **호출부까지** 같이 맞춘다. `oval_image_button.dart`만 복사하고 인트로·마을·BGM 게이트를 옛 고정폭으로 두면 「첫 창문을 밝히기」가 잘리고 BGM이 커진다. 인트로·미션 = `kOvalCompactWidth`+`expandToFitLabel`. BGM = `PlayUiTarget.bgmGate`. 타이틀 두루마리는 `fontSize` 강제 금지(PlayUi 15).
- Credit(또는 크레딧 제목)을 **길게** 누르거나 타이틀 왼쪽 아래 **UI**면 편집 화면. 설정에 **UI 편집** 링크는 없다. `kDebugMode`에 묶지 않는다(릴리스 APK로 맞춘다).
- 로컬 APK UI 편집: **위 미리보기 + 아래 슬라이더** 한 화면. 하단 32%·58% 오버레이로 타이틀을 가리면 실패. 슬라이더는 **지름 22 크림 원 + 금테**. 공개 웹·스토어 빌드에는 없음.

## 타이틀·PWA 상단

- 타이틀에 반짝이는 별 레이어가 있다. 불투명 PNG **위**(타이틀 그림과 같은 칸, 그림 **다음**). 바깥 스택에서 그림 아래에 두면 안 보인다. `TwinklingStarField`를 함부로 빼거나 재배치하지 않는다.
- 나라별 타이틀 PNG는 **1080×2340**. `Title_Image_Starlight Sdoku KR/EN/JP/CN/TW.png`.
- 타이틀 버튼은 여주를 가리지 않게 좁은 폭. 두루마리 위아래가 잘리지 않게 비율 유지. 세로 기준 `alignY` 0.79에서 **두루마리 한 개 높이의 3/8**만큼 아래로 내린다(절반에서 1/8만 다시 올림).
- **APK** 폴드처럼 가로가 넓으면 타이틀은 1080:2340 칸. 양옆은 별 남색. 그림만 `fitWidth`로 키우지 않는다.
- **웹 데모**는 폴드 레터박스를 쓰지 않는다. PC 브라우저는 390×844 폰 프레임 하나. 실제 폰 세로 웹은 화면을 채운다.
- 시스템 뒤로가기 → 양피지 「종료할까요」. 스플래시가 아니라 타이틀에서.
- 오프닝 스토리는 스플래시 직후가 아니라 **새 퍼즐 시작** 다음. 건너뛸 수 있다.
- 인트로 카드 안쪽 패딩은 사방 같다. 점과 버튼은 **한 줄**(왼쪽 점, 오른쪽 버튼). 「다음」과 「첫 창문을 밝히기」는 **같은 스키니 타원 높이**와 **같은 글자 11**. 긴 글은 **가운데만** 가로로 늘리고 한 줄(좌·중·우 세 장). `Image.centerSlice`는 작은 타원에서 그림이 사라지니 쓰지 않는다. 별 끝은 「다음」과 같은 크기. **마을 미션**도 「다음」과 같다(폭 80). BGM 타원은 한 장. 글자는 타원 세로 가운데.
- APK 타이틀 상태바는 남색 `#0E2040`, 아이콘은 흰색. 아침 하늘(난이도·마을)에서 흰 아이콘이 시계를 가리는지는 실기기.
- 웹 `theme-color`와 PWA `manifest.theme_color`는 `#0E2040`. 투명이면 Chrome이 노랗게 칠한다.
- **브라우저 주소창**의 빈 별은 북마크다. 우리 별은 주소창을 없앤 **홈 화면 추가(PWA)** 또는 APK에서만 보인다. 일반 탭·시크릿 탭의 흰 주소창은 정상이다.

## 독립 홍보 랜딩

- `web/landing/index.html`은 Flutter 웹 게임 `web/index.html`과 분리한 홍보 페이지다. 랜딩 수정으로 Flutter 타이틀 화면·버튼·코어 루프를 바꾸지 않는다.
- 랜딩 언어는 `?lang=`이 있으면 그걸, 없으면 브라우저 언어(`ko` / `en` / `ja` / `zh` / `zh-TW`). 헤드라인·CTA·타이틀 PNG를 그 언어로 바꾼다.
- 한국어 기본 카피는 `멈춰버린 밤에` / `아침을 불러오세요.` / `지금 플레이해 보세요`. JS가 꺼져 있어도 이게 보인다.
- CTA는 `../?lang=`으로 Flutter 웹 게임에 랜딩과 같은 언어를 넘긴다. 게임은 OS 언어가 아니라 이 값을 쓴다. 기준 위치에서 버튼 높이의 절반만큼 올린다.
- 광채·빛결·반짝임·hover 움직임은 CTA 내부와 주변에만 적용하고, `prefers-reduced-motion` 환경에서 반복 모션을 끄는다.

- 밤 / 창문 불 / 아침은 **스테이지 클리어 비율**만 본다. `windowPoint` 0.42 미만은 밤, 1 미만은 창문, 1은 아침.

- 체험판 최종판 완료 시 난이도·스테이지·마을이 모두 아침. Play는 10/10, 웹은 5/5.

## 스테이지 카드

- 클리어한 칸 오른쪽 위에 금색 별.
- 누르지 않은 1번을 선택처럼 표시하지 않는다.

## 퍼즐

- 보드·숫자 한 줄·삭제 도구. 클리어 창에서 별빛이 커지며 화면이 스크롤되지 않게 한다.
- 셀 가이드(십자·9칸·같은 숫자)는 **쉬움만**. 보통·어려움은 고른 칸만 노랗다.
- 나갈까요: 양피지. 계속 풀기 / 나가기. 진행은 이어하기에 저장.
- 나갈까요 위 패딩은 공통 `modalPadY`보다 **+8**(아래 양피지 장식이 더 두꺼움). 본문↔버튼 간격은 `rowGap * 1.5`.
- **일시정지:** AppBar 일시정지 → 보드·숫자 입력 차단 오버레이(양피지 「일시 정지」+「계속 풀기」). 아이콘은 정지 중 ▶. 타이머 멈춤.
- **다시 풀기:** AppBar 새로고침 → 확인 양피지 후 `giveUp()` 리셋. 「계속 풀기」면 유지. 지금 판 입력·타이머·실수 지움(이어하기 저장 칸도 그 상태로).
- **플레이 시간:** 퍼즐 위에 어떤 모달·메뉴가 떠 있어도 타이머 정지(설정·나갈까요·다시 풀기·클리어·일시정지 동일). `ModalRoute.isCurrent` + `isPaused`.
- 타원·두루마리 글자 세로: 기본 `buttonTextOffsetY` **0**. 타원 `Text` height는 `buttonStyle`의 **1**(1.05로 덮지 않음). 예전 -1.5는 위에 붙어 폐기.
- 퍼즐 AppBar 자리는 **설정**. 벌레 스킵은 로컬에만 있고, 스토어 빌드에 다시 넣지 않는다.

### 긴 글 = 가운데만 늘림 (꼭)

글자가 길어서 타원 가로를 키울 때 **유일한** 방법이다. 「첫 창문을 밝히기」, 영어 `Light the first window` 포함.

- **한다:** 양쪽 별은 짧은 버튼과 같은 크기. 남는 가로는 **가운데 몸통만**. 좌·중·우 세 장(`_OvalMiddleStretch`).
- **한다:** 양피지 창도 같다. 모서리 말은 고정. 가로는 빨간 띠, 세로는 파란 띠만 늘림(`_ParchmentNineSlice`). `Image.centerSlice` 쓰지 않음.
- **안 한다:** 한 장을 통째로 가로 `BoxFit.fill`. 별이 같이 늘어나고 마지막 글자가 별에 들어간다.
- **안 한다:** `Image.centerSlice`. 스키니 타원에서 버튼이 사라진다.
- **안 한다:** BGM처럼 칩 폭만 쓰는 타원에 세 장/슬라이스를 넣기. 양쪽이 짓눌린 버튼처럼 보인다.
- **안 한다:** 모달 안 타원을 `FittedBox`로 창에 맞춰 줄이거나, `Expanded`로 반씩 늘리기. 닫기·나가기·계속 풀기가 제각각이 된다.
- **안 한다:** 짧은 확인 창을 화면 높이까지 늘리기. 높이는 글+패딩만큼.

코드: `lib/presentation/widgets/oval_image_button.dart`. `expandToFitLabel`이고 폭 > 기준 80일 때만 세 장. 모달 버튼·마을 미션도 같은 인트로 옵션. 두 개짜리 모달 버튼은 `ParchmentModalButtonRow`.

### 하지 말 것

- 타이틀에 19·18을 더하지 않음. 타원을 11 말고 다른 글자로 고정하지 않음
- 긴 글로 타원을 늘릴 때 그림 전체를 늘리지 않음. **가운데만.**
- 모달 타원을 창 높이에 맞춰 줄이거나 가로를 반씩 늘리지 않음. 닫기 규격, 가로는 글자
- 짧은 확인 양피지를 화면 끝까지 늘리지 않음. 높이는 글+패딩(40)
- 양피지 그림 전체를 `BoxFit.fill`하지 않음. 모서리는 두고 가운데만(버튼과 같음)
- BGM처럼 칩 폭만 쓰는 타원에 인트로 3조각·centerSlice를 넣지 않음. 미션은 「다음」과 같음
- 하늘·창문은 스테이지 클리어 비율만
