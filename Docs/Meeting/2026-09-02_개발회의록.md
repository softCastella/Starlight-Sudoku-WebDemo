## 오늘 회의에서 정한 것

- 난이도 뒤에 **멀티스테이지**를 둔다. Easy 20 / Normal 40 / Hard 50. 앞 스테이지를 깨야 다음이 열린다. 같은 스테이지는 같은 퍼즐이다.
- 원문의 **마을 복원 대기 타이머**(5분/15분/1시간, 클리어 시 단축)는 넣지 않는다. 지금은 StarLight로 빵집·도서관·분수 바가 바로 채워진다. `GameBalance`의 타이머 숫자는 쓰이지 않는다.
- 톤은 **파스텔 그림책 마을**. 고딕, 호러, 네온, 기본 Material 블루가 아니다. 글/카드는 크림 양피지 위 숲색 글씨.
- 마을 그림은 **같은 마을 한 장**이다. 밤 / 창문 불 / 낮이 이어지고, 스테이지를 깰수록 아침이 온다.
- 인트로는 스플래시 직후가 아니라 **새 퍼즐 시작**을 눌렀을 때 나온다. 건너뛸 수 있다. 현재는 새 퍼즐마다 나온다.
- 금색은 겨자 브라운(`#C78A00`)이 아니라 **노란 금색 `#F5CC3D`**, 빛 `#FFE56A`.
- 웹 공개 저장소 이름은 `Starlight-Sudoku`이다. Pages 주소는 `/Starlight-Sudoku/`.
- 그린 마을 지도 위에 Material 아이콘을 올리지 않는다. 건물 자리만 누르고, 이름표만 둔다.
- 스테이지 1칸은 가만히 있을 때 빛나지 않는다. 누르는 동안에만 금빛이 돈다.

## 오늘 완료한 내용

### 멀티스테이지

- 난이도 선택 후 스테이지 목록이 열린다.
- 클리어한 칸은 다시 풀 수 있고, 재플레이는 StarLight를 다시 주지 않는다.
- 진행도와 현재 판은 로컬에 저장된다.

### 화면과 연출

- 스플래시: HTML은 흰 화면만. Flutter 로고가 작게 나타났다가 사라진다.
- 홈: 타이틀 그림 전체 배경. 태그라인·저작권 문구는 빼다. 버튼은 화면 아래쪽 중간.
- 인트로 3장: 잠든 마을 → 창문의 불빛 → 아침. 마지막 버튼은 `첫 창문을 밝히기`.
- 난이도 / 스테이지 / 미션: 밤 마을 위에 양피지 카드. 호버·클리어는 금색 테두리와 빛.
- 마을 화면: 지도가 남는 높이를 채운다. 왼쪽 `N / 3개 복원`, 오른쪽 `보유 스타라이트 N`. AppBar에 미션.
- 홈·인트로 주요 버튼에 두루마리 그림(`Button.png`)을 넣었다.

### 배포

- `main`에 현재 웹 빌드를 올렸다.
- GitHub Actions가 Flutter 웹 릴리스를 빌드한다. `base-href`는 `/Starlight-Sudoku/`.
- 공개 주소: https://softcastella.github.io/Starlight-Sudoku/
- 배포 실행: https://github.com/softCastella/Starlight-Sudoku/actions/runs/33535410111
