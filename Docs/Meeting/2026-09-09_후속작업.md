# 2026-09-09 후속 작업 (아침)

어제 밤 작업은 **이 저장소 코드**에 있다. 폰에 깔린 APK와 서명이 달라서 덮어씌우지 못했다. 지우면 기기 진행·슬라이더 값이 같이 날아간다. 아침에 같은 키로 빌드해 덮거나, 실기기에서만 확인하면 된다.

시작 전: `Docs/Harness/검증.md`. APK는 `main`. 웹 공개는 `pages` 푸시만. `sample-v1`은 읽기 전용.

## 아침에 할 일 (순서)

1. **실기기 APK**로 어제 수정을 확인한다. 폰 앱을 지우지 않는다.
   - 스플래시: 로고 때 식별 음성 **한 번만**. 탭해도 다시 안 남. 웹은 스플래시·음성 없음.
   - 타이틀: 코드 별이 불투명 PNG **위**. 그림 아래면 안 보인다.
   - 크레딧: 제목 18, 본문 13. 짧은 가로 창에 글을 축소해 안 보이게 하지 않는다.
   - 편집 패널: 글자 버튼 **초기화** / **저장**. 저장은 값을 화면에 보여 준다. 초기화는 확인 창. 스토어 화면에 넣지 않는다.
2. 난이도·스테이지·마을 하늘은 스테이지 클리어 비율만. 건물 복원량으로 창문을 켜지 않는다.
3. 웹은 필요하면 `pages`만. `main` 푸시로 Pages가 올라가지 않는다.
4. Play 콘솔·키스토어는 아직 하지 않는다.

## 어제 코드에 넣은 것 (폰 미반영일 수 있음)

| 항목 | 내용 |
| --- | --- |
| 스플래시 보이스 | APK만, 로고 등장 1회. 탭으로 재시작하지 않음. `AbsorbPointer`로 흰 화면만 막음 |
| 타이틀 별 | `TwinklingStarField`를 타이틀 PNG **다음**. 앱·웹 같음 |
| 크레딧 | `shrinkContent: false`, 창 비율 `0.92`, 본문 `PlayUi.bodyStyle` (13). FittedBox로 3px까지 줄이지 않음 |
| 편집 패널 | **초기화** / **저장** 글자. 저장=보관+화면에 값. 초기화=확인 후 기본값 |
| Play UI JSON | 내보내기 schema 3. 저장 키는 `play_ui_tune_v2` 유지(기존 폰 값 안 버림) |

관련 파일: `splash_screen.dart`, `splash_voice.dart`, `home_screen.dart`, `credits_dialog.dart`, `play_ui_tuner_panel.dart`, `play_ui_tune.dart`, `Docs/Harness/검증.md`.

## 하지 말 것

- 폰 앱 삭제 후 재설치(진행·슬라이더 값 삭제)
- 편집 패널 **초기화**를 확인 없이 누르기
- `sample-v1` 체크아웃·커밋·머지
- APK 스플래시를 밤하늘로 바꾸기
- 웹에 폴드 레터박스·광고
- 스토어 빌드에 벌레 스킵·UI 슬라이더 노출

## 막힌 것 (아침 참고)

- 갤럭시 S25(`R3CY50FP0QD`) USB 디버깅은 됨. 깔린 패키지는 **출시 빌드**(debuggable 아님)이고, 이 PC 디버그 키와 **서명이 다름**. `adb install -r` 실패. 백업 파일은 0바이트.
- 파일 전송으로 UI 값은 안 나옴. 앱 내부 저장이다.
- 저장을 누르면 값이 나온다. 채팅에 붙이면 중간이 잘릴 수 있다. 잘리면 저장 화면에서 전체를 다시 본다.
- 어제 붙여 넣은 JSON 앞부분은 코드 기본값(11/13/14/15/18, 모달 패딩 40 등)과 같았다. 슬라이더를 다른 숫자로 맞춘 뒤 초기화했으면 그 숫자는 기기에 없다.
