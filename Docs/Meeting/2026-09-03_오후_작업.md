## 오늘 반영한 것

### Play 체험판

- `GameBalance.isTrial = true`. Easy 10판만 있다. Normal / Hard는 0판이라 난이도 화면에 안 보인다.
- 정식 판수는 `fullEasyStageCount` 20 / `fullNormalStageCount` 40 / `fullHardStageCount` 50에 남겨 두었다. `isTrial`만 끄면 전체 게임이 된다.
- GitHub Pages 웹도 같은 플래그를 쓰므로 **웹도 10판 체험판**이다.
- 체험판 아이콘은 `Icon_Starlight_Sudoku_v1_sample.png` (1024 포함).

### 10판 끝난 뒤 리뷰 안내

- 문구: 「체험판은 여기까지입니다.」 / 「응원해주신다면 리뷰를 남겨주시면 큰 힘이 됩니다.」
- 별 5개 + **전송** / **닫기**. 앱은 포그라운드에 둔다.
- **전송**은 Google Play 인앱 리뷰(`InAppReview.requestReview()`)만 연다. 스토어 목록으로 나가는 `openStoreListing()`은 쓰지 않는다. 화면의 별은 안내이고, 실제 별점은 Play 오버레이다.
- 디버그 사이드로드에서는 Play 창이 안 뜰 수 있다.
- 처음에는 타이틀로 완전히 돌아가야만 모달이 떴다. 10판 완료 후 실제 도착지는 **스테이지 선택**이라 아무 창도 없었다.
- 지금은 스테이지 선택·난이도·마을 보기·타이틀 중 현재 화면에 한 번 뜬다. 닫거나 전송하면 `has_seen_trial_end`를 저장해 다시 안 뜬다.

### 낮 배경

- 스테이지 선택은 그 난이도 클리어 비율로 밤→낮이 바뀐다. Easy 10/10이면 낮이다.
- 난이도·마을 그림을 건물 복원과 `max` 하면, 스테이지 3/10인데 난이도·마을만 창문에 불이 들어온다. **하늘·창문은 스테이지 클리어만 본다.** 빵집 5/5 라벨은 그대로 StarLight.
- 체험판 10/10이면 난이도·스테이지·마을이 모두 아침이 된다.

### 그 밖에 오전에 이어서 올라간 것

- 장면별 BGM, 첫 탭 후 타이틀 음악, 틀린 숫자 StarLight 감점
- 긴 번역 문구가 양피지·타원 버튼 안에 들어가게 맞춤
- 타이틀 언어 드롭다운·저작권 탭 레이아웃 조절은 숨김. DEBUG 배너도 끔.

## 의도적으로 안 한 것

- 퍼즐 AppBar의 벌레 버튼(스테이지 스킵). 10판 흐름 확인용으로 **아직 켜 둔다.** 스토어 빌드 전에 꺼야 한다.
- 광고. AdMob은 가입만 했고 코드에는 없다. 웹에는 광고를 넣지 않는다.
- 출시 서명. Android는 아직 디버그 서명이다. Play에는 나중에 keystore 후 `flutter build appbundle --release`.
- 정식판 전환(`isTrial = false`), 달빛 항구 실제 지도
- **타이틀에서 뒤로가기 종료 확인.** 지금은 APK 타이틀에서 뒤로가면 바로 꺼진다. 이따 넣을 것: 「게임을 종료하시겠습니까」 양피지 창 → 확인 시 종료, 취소 시 타이틀에 남기. 난이도·스테이지·마을은 이전 화면으로, 퍼즐은 기존 나가기 확인 그대로.
