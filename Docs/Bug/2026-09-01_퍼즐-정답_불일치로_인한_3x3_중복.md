# 퍼즐-정답 불일치로 인한 3x3 중복 표시

## 기본 정보

- 발견일: 2026-09-01
- 상태: 수정 완료
- 영향도: 높음
- 관련 영역: 스도쿠 퍼즐 생성, 정답 판정, StarLight 보상

## 증상

새 게임을 시작했을 때 하나의 3x3 영역 안에 동일한 숫자가 두 개 이상 나타났다.

추가로, 플레이어가 모든 빈 칸을 올바르게 채워도 퍼즐 완료로 판정되지 않아 StarLight 보상과 완료 다이얼로그가 나타나지 않았다.

## 원인

게임 시작 시 다음처럼 서로 독립적인 생성 호출이 사용되고 있었다.

1. `generatePuzzle(difficulty)`가 첫 번째 완성 보드에서 퍼즐을 생성한다.
2. `generateSolution()`이 두 번째 완성 보드를 새로 생성한다.
3. 첫 번째 퍼즐과 두 번째 완성 보드를 하나의 `SudokuBoard`에 전달한다.

두 완성 보드는 각각 유효한 스도쿠였지만 서로 다른 보드였다. 따라서 퍼즐의 고정 숫자는 화면에서 정답으로 사용하는 보드와 맞지 않을 수 있었다.

## 수정 내용

- `SudokuGenerator.generatePuzzleWithSolution(difficulty)`를 추가했다.
- 이 메서드는 퍼즐과 해당 퍼즐을 만든 정확한 정답 보드를 함께 반환한다.
- `GameNotifier.startNewGame()`은 반환된 퍼즐·정답 쌍을 그대로 `SudokuBoard`에 전달하도록 변경했다.
- 생성된 퍼즐의 모든 고정 숫자가 함께 반환된 정답 보드의 같은 위치와 일치하는지 검증하는 회귀 테스트를 추가했다.

## 재발 방지

- 퍼즐과 정답은 별도의 독립 생성 호출로 조합하지 않는다.
- 퍼즐 생성 API를 사용할 때는 퍼즐과 정답의 쌍을 유지한다.
- 새 퍼즐 생성 로직을 변경할 때는 고정 숫자와 정답의 위치별 일치 여부를 테스트한다.

## 검증

- 스도쿠 생성기 테스트 통과
- 전체 Flutter 테스트 통과
- `flutter analyze` 이슈 없음
- 실제 게임 화면에서 3x3 중복이 사라지고 완료 시 StarLight 보상이 지급되는 것을 확인함
