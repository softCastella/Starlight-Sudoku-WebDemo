## 오늘 반영한 것

### 나라별 타이틀과 문구

- 한국어·영어·일본어·간체·번체 타이틀 그림을 폰/브라우저 언어에 연결했다. 파일 이름은 받은 그대로 `Title_Image_Starlight Sdoku …`이다.
- 홈·스플래시·난이도·스테이지·퍼즐·마을·미션·대화창 남은 문구를 언어 파일에 연결했다.
- 타이틀 왼쪽 위에 테스트용 언어 드롭다운을 달았다. System / 한국어 / English / 日本語 / 简体中文 / 繁體中文. 이번 실행에만 유지된다.

### 타이틀 버튼

- 버튼 위치 기본값을 `alignY 0.79`, `maxWidth 236`, `gap 10`, `fontSize 18`, `scale 1`로 맞췄다.
- 저작권 자리를 짧게 누르면 버튼 위치 조절, 길게 누르면 앱 아이콘 크기 조절이 열린다.

### 앱 아이콘

- 칸을 꽉 채우면 홈 화면 마스크에 잘렸다. 그림은 안쪽에 두고 바깥 남색만 투명으로 바꿨다가, 새 원본 `Icon_Starlight_Sudoku_v4`를 여백 잘라 1024로 맞춘 뒤 웹·안드로이드·iOS에 넣었다.
- v4는 이미 파란 여백이 있는 아이콘이라 66%로 다시 줄이지 않았다. 아이콘 조절 기본 크기는 100%이다.
- 웹 파비콘 캐시 쿼리는 `20260903a`이다. 이미 홈 화면에 깔아 둔 아이콘은 지웠다가 다시 넣어야 바뀐다.

### 마을 보기

- 밤 / 창문 불 / 아침을 투명으로 겹치지 않는다. 복원 전에는 밤, 중간은 창문 불, 다 복원하면 아침 한 장만 보여 선이 이중으로 비치지 않게 했다.
- `2/3 복원`, `빵집 5/5` 같은 글자는 밤·창문 장면에서는 크림색에 그림자를 넣어 또렷하게 했다.

### 글꼴

- 웹에서 한글·일본어·중국어가 X 상자로 떴다가 글자로 바뀌던 것은, 기본 글꼴에 글자가 없어서 대체 글꼴을 받을 때까지 생기던 현상이다.
- `StarlightSans`와 `StarlightSansCJK`를 앱에 넣고, 첫 화면이 열리기 전에 읽어 두게 했다.

### 폰 뒤로가기

- 웹에서는 화면을 쌓아도 브라우저 기록에 안 남아서, 폰 뒤로가기가 곧 앱 종료였다.
- 이제 마을·난이도·오프닝처럼 들어간 화면에서는 이전 화면으로 돌아간다. 퍼즐 중이면 나가기 확인이 먼저 뜬다. 타이틀에서는 바로 꺼지지 않는다.
