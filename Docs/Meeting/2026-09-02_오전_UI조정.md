## 이번에 반영한 것

### 타이틀 화면

- 양피지 버튼을 화면 가운데 전체 너비로 두지 않는다. 왼쪽·좁은 폭으로 두어 **여주가 가려지지 않게** 한다.
- 버튼 이미지 비율은 유지한다. 두루마리 위아래가 잘리지 않게 `BoxFit.contain`을 쓴다.
- 저작권은 **타이틀 이미지에 이미 들어 있다.** Flutter로 `Tyche works` / `© Tyche Spark. All rights reserved.` 문구를 따로 올리지 않는다.
- 하단이 어두워지는 그라데이션은 그대로 둔다.

### 별빛 마을

- AppBar의 기존 **아이콘 + 미션** 자리를 유지한다.
- 그 아래에 작은 가로 타원 `보기` 버튼을 둔다. 눌러야만 물결이 나는 방식은 쓰지 않는다. 평소에도 타원이 보이게 AppBar 높이를 늘렸다.
- 촌스러운 큰 `ElevatedButton`(복원 미션 보기)은 쓰지 않는다.

### 퍼즐 클리어 창

- 별빛 아이콘이 크게 튕기며 커지지 않게 했다. 커지면서 화면이 밀리고 스크롤이 생기던 연출을 뺐다.
- `+N StarLight`는 고정 크기로만 보여 준다.

### 로컬 환경

- Flutter SDK를 Downloads에서 `C:\Users\user\flutter`로 옮겼다.
- 사용자 PATH에 `C:\Users\user\flutter\bin`을 넣었다.
- 확인 버전: Flutter 3.47.2, Dart 3.13.2
- 이미 열려 있던 터미널·Cursor는 재시작해야 `flutter` 명령이 잡힌다.

### 배포

- `main`에 푸시했다. GitHub Actions가 웹 릴리스를 빌드한 뒤 Pages에 올린다.
- 확인 시 시크릿 창을 권장한다.

## 같은 날 오전에 이어서 맞춘 UI (Pages에 이미 포함된 것)

아래는 같은 날 새벽에 이은 조정이며, 이번 배포에도 포함되어 있다.

- 에셋 폴더: `Icon` / `Logo` / `Scene` / `SystemUI`
- 타이틀 이미지: `Title_Image_Starlight Sdoku.png`
- 인트로 `다음` / `첫 창문을 밝히기`: 작은 가로 타원 이미지 버튼
- 난이도 표기: 이지 → **쉬움**, 하드 → **어려움**
- 스테이지 `0/20 클리어` 배너만 반짝임 제거. 숫자 칸의 금색 테두리·누를 때 빛은 유지
- 게임 화면: 스크롤 없이 보드·숫자 한 줄·삭제 도구
- 나갈까요 창: `modal_window` + 계속 풀기 / 나가기 나란히
- 웹 상태바 `theme-color`는 투명 금지 (Chrome이 노랗게 칠함)
- 타이틀 밤하늘 별 레이어
