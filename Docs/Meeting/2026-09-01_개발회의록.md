## 오늘 완료한 내용

### 게임 핵심 안정화

- 퍼즐 생성에 사용한 해답과 게임 정답 판정에 사용한 해답이 달라질 수 있던 문제를 수정했다.
- 생성된 퍼즐과 그 퍼즐의 정답을 같은 쌍으로 전달하도록 변경했다.
- 이로 인해 3x3 영역의 고정 숫자가 중복되어 보이거나, 정답을 모두 입력해도 완료 처리와 StarLight 보상이 발생하지 않던 문제를 해결했다.

### 게임 및 마을 기능

- StarLight 보상, 마을 복원도, 플레이 통계, 진행 중 퍼즐 저장 및 이어하기 기능을 구현했다.
- 마을 지도와 복원 미션 목록을 분리했다.
- 건물별 복원 스토리와 첫 마을 완료 시 다음 에피소드인 달빛 항구 해금 안내를 추가했다.
- 실행 취소를 실제 히스토리 기반으로 구현했다.
- 힌트는 한 판에 3회까지 사용 가능하며, 사용 시 회당 StarLight 10이 감점되도록 적용했다.
- 퍼즐 완료 시 StarLight 보상 카운트업, 기본 효과음·진동 호출, 마을 건물 등장 애니메이션을 추가했다.

### UI 조정

- 타이틀 화면을 스도쿠 보드 중심 구성으로 변경했다.
- 타이틀 화면에 Tyche Spark 및 Tyche works 브랜드를 반영했다.
- 저작권 표기를 `© 2026 Tyche works`로 단순화했다.
- 게임 상단 상태 정보를 한 줄로 통합했다.
  - 왼쪽: StarLight 라벨 및 보상 수치
  - 가운데: 난이도
  - 오른쪽: 경과 시간
- 숫자 입력 패드의 좌우 여백, 버튼 높이, 간격을 줄여 보드 아래 공간을 확보했다.
- 하단 포기 버튼을 제거하고, 상단 뒤로가기에서 저장 후 나가는 확인 흐름을 제공한다.

## 공유 및 배포 논의

- 현재 `localhost` 주소는 개발용이므로 외부 공유가 불가능하다.
- 외부 피드백을 위한 우선 배포 방식은 Flutter 웹 빌드 후 GitHub Pages, Netlify 또는 Vercel에 배포하는 방식으로 정리했다.
- Android APK/AAB 빌드는 Android SDK Command-line Tools 설치 및 라이선스 승인이 필요하다.
- Google Play 배포용 릴리스 서명 keystore는 별도로 준비해야 한다.
